Stay up to date with the latest features, improvements, and bug fixes for ETS2 Dashboard Editor.

May 2025

v0.1.0

Latest Initial Release

new_releases New Features

  • •Drag & drop visual canvas editor powered by Pixi.js for real-time 2D preview.
  • •3D Model Viewer built with Three.js — apply your design to a UV-mapped truck model before export.
  • •Live telemetry connection via SCS SDK — preview dashboard changes in real-time while driving.
  • •One-click Mod ZIP export for instant deployment to ETS2 and ATS.
  • •SII file import/export — load and save existing dashboard configurations.
  • •Custom DDS import with path, color, and transform manipulation.
  • •Full undo/redo history for all editing actions.
  • •Built-in code editor (CodeMirror 6) for advanced scripting.
  • •DDS and PNG texture support with Rust-powered image processing backend.

info Release Notes

  • •Windows only for this initial release. macOS and Linux support planned.
  • •Requires ETS2 or ATS with the SCS Telemetry SDK plugin installed for live preview.
